# Приглашение для Татьяны

Статический одностраничный сайт для GitHub Pages. Сборка и зависимости не нужны.

## Быстрая настройка

- Основные данные события и ссылка для ответа: `content.js`.
- Тексты и структура: `index.html`.
- Цвета и оформление: `styles.css`.
- Фоновое изображение: `assets/nizhny-sunset.jpg`.
- Фотографии можно добавить в `assets/photos/`, затем заменить блоки-заглушки в секции `.polaroids`.

## Локальный просмотр

Из папки проекта запустите:

```bash
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## GitHub Pages

1. Создайте публичный репозиторий, например `tatiana-birthday-invite`.
2. Загрузите в него содержимое этой папки.
3. Откройте **Settings → Pages**.
4. В блоке **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main`, папку `/ (root)` и нажмите **Save**.

Сайт появится по адресу:

`https://mikhailizegov.github.io/tatiana-birthday-invite/`

## Ответ «Буду ❤️»

Пока кнопка копирует ответ в буфер обмена. Чтобы она сразу открывала Telegram, укажите ссылку в поле `replyUrl` внутри `content.js`.
